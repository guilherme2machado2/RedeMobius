Bem vindo ao Projeto Rede Mobius

<h1>Introdução</h1>

<p>Este projeto tem por finalidade simular uma rede de cuidados exclusivamente para Pets</p>

<h2>Tecnologias Utilizadas:</h2>

<h3>Mobius System</h3>

<ul>Spring Boot</ul>
<ul>Java 17</u17
<ul>PostgreSQL</ul>

<h3>App Mobius Interface</h3>

<ul>React Native</ul>


<h2>Estrutura do Projeto:</h2>

<h3>Modulos do Sistema</h3>

<li>Cadastro de usuários: Clientes que podem cadastrar seus pets.</li>
<li>Agendamento de consultas: Sistema de agendamento.</li>
<li>Planos de saúde: Cadastro e gerenciamento de planos.</li>
<li>Loja de medicamentos: Sistema de compra.</li>
<li>Hospedagem: Agendamento de estadias.</li>
